📋 Условия использования

Магический кабинет — сервис для развлечения и самопознания. Все расклады Таро, гороскопы и нумерологические расчёты носят исключительно развлекательный характер и не являются профессиональной консультацией.

🔒 Конфиденциальность

Мы собираем минимум данных: ваш Telegram ID, имя и дату рождения для персонализации. Эти данные используются только для работы приложения и никогда не передаются третьим лицам.

💳 Оплата

Платежи обрабатываются через Telegram Stars. Подписка активируется мгновенно после оплаты. Возврат осуществляется через поддержку Telegram.

🗑️ Удаление данных

Вы можете запросить полное удаление ваших данных через раздел Профиль → Удалить аккаунт. Все данные будут удалены в течение 24 часов.

📬 Контакт

По всем вопросам обращайтесь через кнопку Поддержка в приложении.
